# LaTeXDa

数式を見て、そのソースとなるLaTeX記法を一文字ずつ入力するブラウザタイピングゲームです。流れてくる問題を制限時間内にできるだけ多く解き、スコア・正確率・コンボを競います。

## ゲーム内容

- レンダリングされた数式、入力すべきLaTeX正答、実際の打鍵内容を縦に表示
- 正答表示はゲーム中でもボタンまたは `F2` で自由に切り替え
- 正しい文字だけが入力欄に進む寿司打風の一文字判定
- 問題ごとの「プレート制限時間」とコース全体の制限時間
- 正打鍵、問題難易度、連続正解コンボに応じたスコア
- ミス時の減点、正確率、流れた問題数、最大コンボを集計
- コース別ハイスコアをブラウザの `localStorage` に保存
- タブが非表示になった場合は自動で一時停止
- 45問の基礎・標準・発展LaTeX問題を収録

オリジナルの画像・音源・コードは使用せず、タイピングゲームの仕組みを独自実装しています。

## コース

| コース | 制限時間 | 出題範囲 |
| --- | ---: | --- |
| お手軽 | 60秒 | 上付き・下付き、分数、ルート、基本記号 |
| おすすめ | 90秒 | 総和、積分、極限、行列、偏微分など |
| 高級 | 120秒 | 無限級数、変換、方程式、発展的な環境記法 |

## 操作

- 半角英数でLaTeX記法を入力
- `F2`: LaTeX正答の表示・非表示
- `Esc`: 一時停止・再開
- 誤入力は進まず、次に必要な文字が案内されます
- 貼り付けは無効です

## 起動

ビルドは不要です。リポジトリ直下を任意の静的HTTPサーバーで配信してください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。数式レンダリングにはKaTeX CDNを利用するため、初回表示時にはインターネット接続が必要です。

## テスト

Node.js 20以上を使用します。

```bash
npm run check
npm test
```

## Sitesへのデプロイ準備

Sitesのbuildless Worker構成に対応しています。既存のブラウザゲームはそのまま保持し、ビルド時にHTML・CSS・JavaScriptをWorkerの静的レスポンスへインライン化します。

```bash
npm run validate
```

このコマンドは `dist/server/index.js` と `dist/.openai/hosting.json` を生成し、Workerが `default.fetch` を公開していることを検証します。Sitesでサイトを作成すると、Sites側のプロジェクトIDが `.openai/hosting.json` に追加されます。デプロイはSitesのチェックポイント操作を実行した時点で開始されます。

ゲームエンジンはDOMから分離されており、文字判定、問題デッキ、得点、プレート失効、全体タイマーをNode.js標準テストランナーで検証します。
