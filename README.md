# LaTexDa

数式を見て対応するLaTeX記法をタイプする、制限時間制のブラウザゲームです。ベルト上の数式が流れ切る前に正答を入力し、残り時間・難易度・コンボに応じたスコアを競います。

## ゲーム内容

- KaTeXでレンダリングした数式を出題
- 数式の下に「正答LaTeX」と「実際に入力した文字列」を表示
- 正答LaTeXはゲーム中でもスイッチで表示／非表示を切替可能
- 30秒・60秒・120秒の3コース
- 問題ごとの流下タイマー、見送り判定、コンボ、速度ボーナス
- 正解数・最大コンボ・正確性・CPM・コース別ハイスコアを結果画面に表示
- 初級から上級まで36問を収録
- 貼り付けを禁止し、実際のタイピング練習として利用可能
- レスポンシブ対応、キーボード操作とアクセシビリティを考慮

## 起動方法

ビルドは不要です。リポジトリ直下で静的サーバーを起動してください。

```bash
npm run serve
```

その後、ブラウザで `http://localhost:4173` を開きます。Pythonが使えない環境では、任意の静的Webサーバーでも動作します。

## テスト

Node.js 18以上で、依存パッケージを追加せずにコアロジックのテストを実行できます。

```bash
npm test
```

## スコア計算

1問ごとの得点は、次の要素から計算します。

- LaTeX文字列の長さ
- easy / medium / hard の難易度ボーナス
- 問題が流れ切るまでの残り時間
- 連続正解コンボ（最大2.5倍）
- 選択コースの倍率

問題を見送るとコンボは0に戻ります。正答の表示／非表示は得点には影響しないため、練習時は表示、腕試しでは非表示という使い分けができます。

## ファイル構成

```text
.
├── index.html               # 画面構造とKaTeX読込
├── styles.css               # UI・ベルト・寿司プレートの表現
├── src/
│   ├── game-core.js         # 判定、得点、時間、問題選択の純粋ロジック
│   ├── main.js              # ゲーム状態とDOM制御
│   └── questions.js         # 出題データ
└── tests/
    └── game-core.test.mjs   # Node.js標準テスト
```

## 外部リソース

数式描画にKaTeX 0.16.11をjsDelivr経由で読み込みます。読み込みに失敗した場合も、問題のLaTeX文字列をプレーンテキストで表示します。
