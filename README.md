# LaTexDa

表示された数式を見て、その **LaTeX記法を正確に入力する** 制限時間制のブラウザタイピングゲームです。ビルドなしで動作し、ゲーム中はLaTeX正答の表示・非表示をいつでも切り替えられます。

## 主な機能

- 60秒・90秒・120秒のタイムコース
- 初級・標準・上級の出題レベル
- KaTeXによる数式レンダリング
- スコア、コンボ、クリア数、精度、CPMのリアルタイム集計
- LaTeX正答表示のゲーム内切り替え（ボタンまたは `Alt + A`）
- 入力ミスの可視化と貼り付け防止
- コース別ベストスコアのブラウザ保存
- PC・スマートフォン対応、キーボード操作とアクセシビリティ配慮
- Node.js標準テストランナーによるゲームロジックのテスト

## 起動

ES Modulesを利用するため、ローカルHTTPサーバーから開いてください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

Node.jsがある場合は、次のコマンドでも起動できます。

```bash
npx serve .
```

## テスト

```bash
npm run check
npm test
```

外部npmパッケージは不要です。数式描画のみ、ブラウザ上でCDN配信のKaTeX 0.16.11を読み込みます。

## 操作

1. 制限時間と出題レベルを選んでゲームを開始します。
2. 数式の下に表示されるLaTeX記法を、半角英数で入力します。
3. 完全一致すると自動的に次の問題へ進みます。
4. `Backspace` で修正できます。正答表示は `Alt + A` または画面上のボタンで切り替えられます。
